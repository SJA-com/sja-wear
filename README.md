# SJA Wear

Premium streetwear, fitness gear, and modest fashion — printed on demand, designed with purpose. A fashion brand by SJA.

## About

SJA Wear is a fashion brand under the SJA conglomerate. We make real clothing for real people — premium quality, clean designs, and collections that cover streetwear, gym, and modest fashion. No gimmicks. Just well-made apparel, printed on demand.

## Collections

- **Men's** — Premium tees, hoodies, and joggers built for everyday confidence.
- **Women's** — Modern streetwear and essentials designed with intention and edge.
- **Fitness Wear** — Performance gym wear — leggings, compression tops, and training gear.
- **Modest Fashion** — Thoughtfully designed modest pieces — full coverage, full style, zero compromise.
- **Accessories** — Caps, tote bags, and extras to complete the look.

## Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/)
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4
- **Fonts:** Geist Sans & Geist Mono
- **Storefront:** Shopify (coming soon) with Printful print-on-demand fulfilment

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project Structure

```
src/
  app/
    layout.tsx    # Root layout with metadata and fonts
    page.tsx      # Landing page — hero, collections, waitlist, shop preview
    globals.css   # Global styles and Tailwind config
public/

```
